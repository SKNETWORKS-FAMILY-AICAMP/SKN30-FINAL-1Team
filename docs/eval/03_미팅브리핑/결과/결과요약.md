# 미팅 브리핑 평가 결과

계약관리 Agent 가 만드는 미팅 브리핑의 품질을 미팅 누적 깊이별로 평가했다.

- 케이스 **30건** (고객사 체인 6 × 깊이 5)
- 전체 평균 **89.8%**
- 프롬프트 버전 `contract_management.generate_briefing.v13`
- 데이터셋·실행·채점 검사 **2,545건 전부 통과**

## 입력 규모

브리핑이 실제로 받는 확정 보고서와 같은 분량·구조로 만들었다.

| 항목 | 값 |
|---|---|
| 보고서 | 180건 (핵심 52 · 일상 기록 128) |
| 핵심 보고서 평균 | 1,065자 (딜 본문 평균 909자) |
| 일상 기록 평균 | 377자, 결정·요청·수치 없음 |
| 10회차 누적 입력 | 약 5,400자 |
| 30회차 누적 입력 | 약 16,900자 |

## 깊이별

| 미팅 누적 | 건수 | 평균 | 최저 | 필수 누락 | 부분 충족 | 해결건 재등장 | 중대 오류 | RAG 미호출 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 1회 (첫 미팅) | 6 | 95.1% | 94.1% | 0 | 0 | 0 | 0 | 0 |
| 3회 | 6 | 98.0% | 88.2% | 0 | 0 | 0 | 0 | 0 |
| 5회 | 6 | 95.8% | 86.8% | 0 | 1 | 0 | 0 | 0 |
| 10회 | 6 | 79.9% | 52.9% | 4 | 0 | 0 | 0 | 2 |
| 30회 | 6 | 80.4% | 68.8% | 2 | 5 | 3 | 0 | 1 |

**10회차에서 크게 떨어진다.** 1~5회차는 95~98% 지만 10회차 79.9%, 30회차 80.4% 다.

브리핑이 한 번에 읽는 보고서는 최신 3건뿐이고 그 너머는 RAG 로만 닿는다. 10회차 이상에서 RAG 를 호출하지 않은 3건은 창 밖 미해결 이슈를 통째로 놓쳤다. 30회차에서는 이미 해결된 사안을 다시 올린 경우가 3건, 필수 주제를 부분적으로만 다룬 경우가 5건, 통째로 놓친 경우가 2건이다.

## 고객사 체인별

| 체인 | 건수 | 평균 | 최저 | 필수 누락 | 중대 오류 |
|---|---:|---:|---:|---:|---:|
| 한빛병원 — 표준 | 5 | 95.2% | 86.2% | 1 | 0 |
| 청산네트웍스 — 전부 종결 | 5 | 93.6% | 83.8% | 0 | 0 |
| 한울제약 — 노이즈 극단 | 5 | 92.6% | 75.0% | 0 | 0 |
| 세종의료재단 — 딜 0건 | 5 | 92.6% | 68.8% | 0 | 0 |
| 대양산업 — 문서 충돌 | 5 | 83.0% | 55.9% | 2 | 0 |
| 미래로병원 — 값 변경 다수 | 5 | 82.0% | 52.9% | 3 | 0 |

값이 여러 번 바뀌는 체인(82.0%)과 보고서·문서 값이 어긋나는 체인(83.0%)이 가장 낮다.

## 코드로 확인한 것

| 검사 | 결과 |
|---|---|
| 존재하지 않는 근거 ID 인용 | 0건 |
| 근거 없어 필터에 삭제된 하이라이트 | 0건 |
| 필요한 RAG 호출 누락 | 3건 |
| 불필요한 RAG 호출 | 0건 |
| 중대 오류 (발언 왜곡·미합의를 합의로 등) | 0건 |

근거를 지어내거나 고객 발언을 왜곡한 사례는 없다. 실패는 **창 밖 과거 기록을 찾아 읽는가** 와 **이미 끝난 일을 접는가** 에서 나온다.

## 대표 실패

**RAG 미호출로 필수 주제 전부 누락** (`miraero-d10` 52.9%, `daeyang-d10` 55.9%)

두 건 모두 RAG 를 한 번도 호출하지 않았다. 미래로병원은 자동화 대상 검사 항목과 당시 장비 수량(20대)을, 대양산업은 설비 유지보수 종료 시점 미확인 건을 놓쳐 필수 주제 커버리지가 0 이다.

**여러 미해결 이슈 중 일부만 반영** (`daeyang-d30` 70.8%)

좌석 수 충돌과 유지보수 요율 재협상은 부분적으로만 짚었고 구형 설비 연동 미검증 건은 놓쳤다. 이 케이스도 RAG 를 호출하지 않았다.

**해결된 사안 재등장** (`sejong-d30` 68.8%, `hanul-d30` 75.0%)

이미 해소된 예산 편성 주기·결재 물량 미집계·전자결재 확장 취소 이슈를 다시 하이라이트로 올렸다.

## 채점 방식

| 항목 | 배점 | 누가 |
|---|---:|---|
| 하이라이트 선택 | 25 | 코드 (주제별 판정에서 계산) |
| 상태 추적 | 15 | 코드 (재등장·옛 값 사용) |
| 사실 정확성 | 20 | LLM |
| 추천 행동 | 20 | LLM |
| 즉시성·가독성 | 10 | LLM |
| 부족한 정보 | 10 | LLM |

상태 변화가 없는 슬라이스는 상태 추적을 빼고 85점 만점으로 환산한다. 주제별 판정만 LLM 이 하고 점수 산술은 코드가 한다.

## 한계

- 합성 데이터이며 실제 고객 미팅이 아니다.
- 같은 케이스라도 LLM 응답은 매번 달라진다. 절대 점수보다 깊이별 경향을 본다.
- 참고자료(계약서·견적서·제품설명서) 자체의 품질은 자료요약 Agent 평가에서 따로 다룬다.
