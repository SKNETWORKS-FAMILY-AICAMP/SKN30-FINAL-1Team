# sql/

스키마와 시드 SQL. **여기 있는 SQL 이 DB 의 기준입니다.**

## 작업 순서

1. `sql/` 에 파일 추가 — 파일명으로 실행 순서를 알 수 있게
   `001_create_users.sql`, `002_add_report_index.sql`
2. Supabase 대시보드 → SQL Editor 에 붙여넣어 실행
3. `app/models/` 의 ORM 모델을 방금 만든 테이블에 맞춰 수정
4. PR 에 **어떤 SQL 을 적용했는지** 적는다

4번이 중요합니다. 적용 이력을 자동으로 추적해 주는 도구가 없어서, PR 기록이 유일한 단서입니다.

## 주의

- **모델(`app/models/`)만 고치면 DB 는 바뀌지 않습니다.** SQL 이 먼저입니다
- **이미 적용한 파일은 수정하지 않습니다.** 새 파일을 추가하세요.
  수정하면 아직 적용 안 한 팀원과 이미 적용한 팀원의 DB 가 달라집니다
- `psql` 로 직접 붙을 때는 **포트 5432(session)** 를 씁니다.
  앱이 쓰는 6543 은 transaction pooler 라 DDL 이 제대로 걸리지 않습니다
